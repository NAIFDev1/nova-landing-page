# Design development

The user rejected the initial cobalt marketing-page rebuild because it resembled Forge and requested a radical interface change. The chosen replacement is a complete working app shell rather than another hero/feature/pricing scroll.

The product remains an English portfolio concept for a fictional task platform. The first screen is a real editable project, with fixed sidebar navigation, separate screens, local persistence, and data-derived counts.

Taste direction: Editorial greeting, app mode, seed 515250686. Its open-plane sidebar, fluid sheet, restrained density, and one level of tonal task panels provide the app grammar. Brand mapping uses a neutral studio ground, olive ink, and a citron action/progress identity. No marketing composition is reused.

On this screen, NOVA's launch tasks become the material itself. The screen answers: what needs doing next in this project? The next-task line, editable task state, and computed project progress answer it with one shared dataset.

The active Impeccable Operate contract is `.impeccable/surfaces/src-studio-jsx.md` (seed:2b80d3b536aa159b). Design and implementation are delegated by the user. The rejected landing implementation and its obsolete components have been removed.

No stock photography or generated raster is needed: the product is the visual material. Self-hosted Stack Sans fonts include their licenses. Lucide supplies consistent controls; the NOVA mark is authored SVG geometry.
